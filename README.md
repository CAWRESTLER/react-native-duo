# @cawrestler/react-native-duo

Native iPhone Duo layout, toolbar, scene, hinge, and camera APIs for React Native

## Installation


```sh
npm install @cawrestler/react-native-duo
```


## Usage


```js
import { ReactNativeDuoView } from "@cawrestler/react-native-duo";

// ...

<ReactNativeDuoView color="tomato" />
```
